## Site structure

Plain HTML, CSS and JavaScript. No dependency installation or build step is required.

- `index.html`: content and bilingual text
- `assets/portfolio.css`: responsive layout and styling
- `assets/portfolio.js`: language switch, filters and email copy
- `assets/system.svg`: conceptual system illustration, not a test screenshot
- `404.html`: retired or missing page notice

Serve locally with `python -m http.server 8000` and open http://localhost:8000.

GitHub Pages serves the `/docs` folder on the default `main` branch. The previous root source is retained for reference and is outside the publishing folder. `.nojekyll` keeps this a static site.
